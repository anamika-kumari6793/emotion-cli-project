# Emotion Detection CLI

This is a Python-based CLI project that detects emotions from user input text.

## Features
- Detects emotion (Happy, Sad, Angry, Neutral, Excited)
- Saves history with timestamp
- View and clear history
- User-friendly menu system

## Technologies Used
- Python
- TextBlob (NLP)
- JSON (data storage)

## How to Run

1. Install dependencies:
pip3 install textblob
python3 -m textblob.download_corpora

2. Run the program:
python3 main.py

## Project Structure
- main.py → Main program
- history.json → Stores user data
